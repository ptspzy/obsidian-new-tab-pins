# Changelog

All notable changes to New Tab Pins are documented here.

## 0.1.2 — 2026-10-01

- Fix extra New Tab Pins tabs appearing when a vault is restarted or its layout is restored ([#4](https://github.com/ptspzy/obsidian-new-tab-pins/issues/4)).
- Search all vault files by title or path, including Bases, canvases, and attachments ([#5](https://github.com/ptspzy/obsidian-new-tab-pins/issues/5)).
- Show file extensions for non-Markdown search results and only offer pinning for supported Markdown files.

Existing saved home tabs are preserved. Pinning and the recent-note list remain Markdown-only.

## 0.1.0 — 2026-07-30

Initial public beta.

- Open a browser-like home view for an Obsidian vault.
- Pin and unpin Markdown files from commands and the file explorer.
- Drag files onto the home view and reorder pinned notes.
- Search Markdown files by title or path.
- Reopen recently modified notes.
- Customize the title, subtitle, density, and empty-tab behavior.
